# 体适能 2.0.25 适配说明

本文记录 FuckTSN 对 `com.bxkj.student` 2.0.25 的适配点，便于后续版本升级时快速定位。

## 背景

2.0.25 的加固方案从 2.0.22 的 360 加固切换为 **SecShell**：

- 外层 `classes.dex` 只保留壳代码（`com.SecShell.SecShell.*`）；
- 真实业务 DEX 被加密存放在 DEX 尾部，运行时解密为 8 个 DEX、约 5.2 万个类；
- R8 将原先的 `com.bxkj.student.v2.common.utils.safe.*` 安全类重命名到**默认包**，类名变成 `ce`、`cj4` 等。

因此旧版的 `safe.c/d/f/g/h` Hook 全部失效，需要按新类名和新的启动总控重新适配。

## 类名映射

| 2.0.18 旧类 | 功能 | 2.0.25 新类 | Hook 方法 | 返回值 |
|---|---|---|---|---|
| `...safe.c` | Debug 检测 | `yj0` | `d()` | `false` |
| `...safe.d` | 模拟器检测 | `tz0` | `a()` | `false` |
| `...safe.f` | Hook 检测 | `rp1` | `a()` / `b()` / `c()` | `false` |
| `...safe.g` | Root 检测 | `cj4` | `d()` | `false` |
| `...safe.h` | TracerPid | `b15` | `a()` | `false` |
| — | 启动总控 | `ce` | `b()` / `a()` | 空实现 |
| — | 签名包装 | `a12` | `c(Context)` | `true` |
| `Transform` | 原生签名 | `com.google.android.datatransport.Transform` | `d(Context)` | `true` |

## 启动检测链

`com.bxkj.student.App.onCreate()` 会调用 `ce.a.b()`，顺序执行：

1. `yj0.d()`：Debugger / 22 端口 / debuggable
2. `SafeGuardThread`：每 100ms 检查 `Debug.isDebuggerConnected()` 与 `b15.a()`
3. `tz0.a()`：模拟器（`libemulator_check.so` + Build 属性 + qemu 文件）
4. `rp1.c()`：`/data/local/tmp/frida-server` 或 `XposedBridge` 类
5. `b15.a()`：`/proc/self/status` 的 `TracerPid`
6. `cj4.d()`：`test-keys`、10 个 su 路径、`which su`
7. `a12.c()` → `Transform.d()`：原生签名/正版校验

任一命中都会 `System.exit(0)`。模块直接 Hook `ce.b()` 为空实现，跳过整条链；同时保留各单项 Hook，覆盖跑步入口 `k55.a0()` 的二次校验（错误码 1001–1006）。

## 加载策略

SecShell 使用 `InMemoryDexClassLoader` 加载真实 DEX，因此：

1. Hook `ClassLoader.loadClass(String)` 与 `loadClass(String, boolean)`，等待安全类加载后立即 Hook；
2. 在 `com.bxkj.student.App.onCreate()` 前主动 `XposedHelpers.findClass` 加载 `ce/cj4/tz0/rp1/b15/yj0/a12/Transform`，避免竞态；
3. 使用线程安全的 `hookedClasses` 集合，避免多线程重复 Hook。

## 部署要求

- 在 LSPosed 中启用模块，并勾选 `com.bxkj.student`；
- 如果体适能在 Magisk DenyList 中，需要移出 DenyList，否则 LSPosed 无法注入；
- 删除 `/data/local/tmp/frida-server`，否则 `rp1.a()` 会命中；
- 不修改 `Transform` 的签名/加密方法（`v/u/s/t/a/x/r/w`），实际网络请求仍使用原生逻辑。

## 验证

测试环境：Android 10、Magisk + LSPosed 1.9.2。

关键日志：

```text

FuckTSN:  SafeGuard(ce.b) Hook成功: ce
FuckTSN:  Hook检测类(rp1.c) Hook成功: rp1
FuckTSN:  签名包装类(a12.c) Hook成功: a12
FuckTSN:  Transform.d 原生签名校验 Hook成功
FuckTSN: [2.0.25] SafeGuard.ce.b() -> 跳过全部启动检测
```

运行结果：App 稳定停留在 `com.bxkj.student.v2.ui.MainActivity`。

## 已知限制

- R8 重命名后的类名可能在后续版本再次变化，需要重新脱壳确认；
- `hookProcessExit()` 会拦截进程内的正常 `System.exit`，如不需要可移除；
- 本仓库不包含签名 APK，APK 需自行构建；
- 仅用于学习交流和安全研究，请遵守相关法律法规。
