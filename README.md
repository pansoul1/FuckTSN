# FuckTSN

> 体适能 Xposed 模块 - 极简、高效、全面的检测绕过方案

## ✨ 功能特性

- **Root / 安全检测绕过** - 完整绕过 Root、Xposed、模拟器等安全检测
- **自动跳过** - 广告、弹窗、隐私协议、锻炼说明一键跳过
- **账号随机设备指纹绑定** - 每个账号独立设备身份，防关联检测
- **设备信息查看** - 在关于页面底部查看当前设备指纹
- **账号快速选择与自动保存** - 多账号管理，一键切换登录

## 📥 下载安装

### 系统要求

- Android 10+ (API 29+)
- LSPosed 或其他 Xposed 框架
- 目标应用：**体适能 2.0.15 - 2.0.17**

### 安装步骤

1. 下载最新版本 APK
2. 安装到手机
3. 在 LSPosed 中激活模块
4. 勾选目标应用：**体适能**
5. 重启体适能应用

## 🚀 使用说明

### 基础使用

1. 打开 FuckTSN 应用，确认模块状态为"已激活"
2. 打开体适能应用，所有功能自动生效
3. 无需任何额外配置

### 账号管理

- **快速切换**：登录页面点击右下角 `···` 按钮选择账号
- **手动添加**：长按 `···` 按钮可手动添加账号
- **设备指纹**：每个账号自动绑定独立的设备 ID 和型号

### 设备信息查看

- 进入体适能 → 我的 → 关于
- 页面底部会显示当前设备指纹信息
- 点击可复制设备 ID
